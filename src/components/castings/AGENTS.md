# AGENTS.md — src/components/castings

- The casting details drawer (`CastingSidePanel`) is window-edge flush: its own `border-l border-border` is the separator (no rounded corners even in overlay), it spans `100dvh` and reaches the window's right edge via `--panel-extra`, with content capped at 352px. Open state lives in `useCastingDetailsPanel` so the host page can show a header action while closed; host pages cancel the admin wrapper padding (`md:-mt-16 md:-mb-8` root, `md:pt-16` content column). Why: the drawer must reach window edges.
- List rows sharing the page with the casting details drawer (`RoleCard`, `RoleShortlistRow`) wrap in `@container` and switch stacked/inline layouts with `@[640px]:` variants, never `md:`. Why: the drawer reduces row width. Avatar stacks come from the shared `TalentAvatarStack`: `md` inline, `sm` when stacked, toggled by `@[640px]:` display classes.
- Talent status labels (Minore, codice fiscale) come only from `TalentStatusPill` (`MinorPill`/`FiscalPill`); rows beside the drawer use the `withIcon={false}` variant (uniform horizontal padding) and stack the pills on their own line below `@[640px]`. Why: one label style everywhere, and names stay readable instead of truncating.
